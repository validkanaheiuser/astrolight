# Lucky65 protocol — extension v3

VID 0603 / PID 0351. Config HID collection FF02:0001, Feature report 7, 620 bytes including report ID. Lighting protocol remains as described in PROTOCOL-v1.md.

## Keymap

Source evidence: vendor JupengSeries.KeyAssigntoData / SendKeyMatrix2Device, decoded from the locally installed app.

- bytes 0..2: 07 03 (fnMode + 1), fnMode 0 or 1.
- bytes 3..7: zero.
- bytes 8..619: 3 layers × 102 matrix slots × 2 bytes per slot.
- Each slot stores flags then code.
- Default: flags 00, normal default HID code (including on Fn tables; firmware interprets flag 00).
- Explicit key/media/mouse: flags 80, vendor code.
- Combination: flags 80 | modifier mask (Ctrl=1, Shift=2, Alt=4, Win=8), basic HID keycode.
- Macro: flags 80, code F0 + slot (0..9).

All 71 logical keys, including currently hidden split-space/ISO positions, retain entries. Other matrix slots stay zero. Writes affect all three tables. No readback command has been established.

## Macro

Source evidence: vendor MacroToData and SetMacroKey.

- bytes 0..3: 07 05 01 slot.
- bytes 4..7: zero.
- bytes 8..263: macro payload (256 bytes), remaining bytes zero.
- payload 0..1: repeat count, big endian.
- payload 2 onward: events of 3 bytes. First two bytes: delay big endian, bit 15 marks key down; last byte: HID code.
- Unused payload bytes zero. Maximum 84 complete events: 2 + 84 × 3 = 254.
- Enforce delay 20..32767 ms, balanced press/release, repeat 1..1000 in Astrolight. Only standard keyboard HID events in macro editor.
- Config write followed by 100 ms wait; each macro write followed by 200 ms wait, following original pacing.

Astrolight reuses library slot IDs for multiple bindings; vendor app allocated slots per assignment. The encoding is identical for the same slot. Macro writes and streaming RGB are serialized on the same worker. RGB resumes after configuration I/O, so applying remap/macros causes a short visible pause; editing does not.

## Verification

`fixtures/vendor-keymap.bin` and `fixtures/vendor-macro.bin` were generated by calling the vendor's original functions with mocked HID output: Ctrl+A on Base Esc, macro on Fn1 key 1, Volume+ on Fn2 key 2, fnMode 1, a two-event A macro repeated twice. Unit test `matches_vendor_reports_byte_for_byte` compares both full 620-byte reports.

No firmware flash, reset or bootloader command is used. On-device persistence and actual macro execution after write have not been confirmed in this release's test run.
